# MX Goods for Cheap: Settlement Dashboard

Interactive dashboard built on a marketplace settlement ledger (Mexico store, 1–19 Oct 2026, amounts in MXN).

**Live page:** https://sanjibsamadder.github.io/mx-settlement-dashboard/

It mirrors a Power BI report (star-schema model, DAX measures) across four pages:

1. **Overview**: net earnings, order payments, paid orders, units, AOV, payout %
2. **Fees & Payout**: waterfall from order payments to net earnings, ledger by category
3. **Products & Regions**: payments by product and ship state
4. **Order Reconciliation**: net earnings per order and orders without payment in the period

Headline figures: MX$331,866 order payments, MX$279,004 net earnings (84.1% payout), 341 paid orders, 384 units.
